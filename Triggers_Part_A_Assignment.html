SQL Server Triggers — Part A Assignment: AFTER Triggers

Goal: Apply what you learned in the Part A tutorial by writing AFTER INSERT, AFTER UPDATE, and AFTER DELETE triggers for a small library database. You will audit changes, log messages, enforce business rules with ROLLBACK + THROW, fix a broken trigger, and predict trigger results.
Total: 20 points.

1. Instructions

  1. Work in a practice database in SSMS.
  2. Complete the tasks in order. Later tasks depend on the data left by earlier ones.
  3. For every task, write your trigger, then run the test script given in the task exactly as written.
  4. Tasks 1–3 create triggers that stay in place. In Tasks 4–9, drop your trigger after testing, as the task tells you.
  5. A test statement that is expected to fail is followed by GO. An error in a trigger stops the rest of the batch.
  6. Every trigger must start with SET NOCOUNT ON and must work correctly when a statement affects many rows.

3. Database setup

Run this script first. Warning: it drops existing tables with these names.

DROP TABLE IF EXISTS dbo.BookArchive, dbo.LibraryLog, dbo.BookAudit, dbo.Books;
GO
CREATE TABLE dbo.Books (
 BookID INT PRIMARY KEY,
 Title NVARCHAR(100) NOT NULL,
 Author NVARCHAR(80) NOT NULL,
 Copies INT NOT NULL,
 IsActive BIT NOT NULL DEFAULT 1
);
CREATE TABLE dbo.BookAudit (
 AuditID INT IDENTITY(1,1) PRIMARY KEY,
 BookID INT NOT NULL,
 ActionType VARCHAR(10) NOT NULL,
 OldCopies INT NULL, NewCopies INT NULL,
 ChangedBy SYSNAME NOT NULL DEFAULT SUSER_SNAME(),
 ChangedAt DATETIME2 NOT NULL DEFAULT SYSDATETIME()
);
CREATE TABLE dbo.LibraryLog (
 LogID INT IDENTITY(1,1) PRIMARY KEY,
 Message NVARCHAR(200) NOT NULL,
 LoggedAt DATETIME2 NOT NULL DEFAULT SYSDATETIME()
);
CREATE TABLE dbo.BookArchive (
 BookID INT NOT NULL, Title NVARCHAR(100) NOT NULL,
 Author NVARCHAR(80) NOT NULL, Copies INT NOT NULL,
 DeletedAt DATETIME2 NOT NULL DEFAULT SYSDATETIME()
);
GO

Part C — Business-rule and logging triggers (7.5 points, 1.5 points each)

Each of these triggers is tested and then dropped.

Task 4 — AFTER INSERT: at least one copy. Create dbo.trg_Books_MinCopies. If any new book has fewer than 1 copy, roll back the INSERT and raise error 50001 with the message A new book must have at least 1 copy.
-- Test
INSERT INTO dbo.Books(BookID,Title,Author,Copies) VALUES (5,N'Empty Book',N'Nobody',0);  -- should fail
GO
INSERT INTO dbo.Books(BookID,Title,Author,Copies) VALUES (5,N'Learning SQL',N'Beaulieu',2); -- should work
SELECT * FROM dbo.Books;
DROP TRIGGER dbo.trg_Books_MinCopies;
📷 Screenshot the error message and the Books table.
Task 5 — AFTER UPDATE: log title changes. Create dbo.trg_Books_TitleChange. When a title changes, write this message to LibraryLog: Title changed from <old title> to <new title>. Write nothing if the title did not change.
-- Test
UPDATE dbo.Books SET Title = N'Fundamentals of Database Systems' WHERE BookID = 1;
UPDATE dbo.Books SET Title = Title WHERE BookID = 2;   -- same title: no message
SELECT Message FROM dbo.LibraryLog ORDER BY LogID;
DROP TRIGGER dbo.trg_Books_TitleChange;
📷 Screenshot the LibraryLog results.
Task 6 — AFTER UPDATE: limit large reductions. Create dbo.trg_Books_LimitReduction. One UPDATE may not reduce a book's Copies by more than 5. If it does, roll back and raise error 50002 with the message Copies cannot be reduced by more than 5 at once.
Hint: you need both the old and the new value.
-- Test
UPDATE dbo.Books SET Copies = Copies - 6 WHERE BookID = 2;   -- should fail
GO
UPDATE dbo.Books SET Copies = Copies - 2 WHERE BookID = 2;   -- should work
SELECT BookID,Copies FROM dbo.Books WHERE BookID = 2;
DROP TRIGGER dbo.trg_Books_LimitReduction;
📷 Screenshot the error message and the final Copies value.
Task 7 — AFTER DELETE: archive deleted books. Create dbo.trg_Books_Archive. Copy every deleted book (BookID, Title, Author, Copies) into BookArchive.
-- Test
DELETE FROM dbo.Books WHERE BookID = 5;
SELECT * FROM dbo.BookArchive;
DROP TRIGGER dbo.trg_Books_Archive;
📷 Screenshot the BookArchive results.
Task 8 — AFTER DELETE: block deleting active books. Create dbo.trg_Books_BlockActiveDelete. If any deleted book has IsActive = 1, roll back and raise error 50003 with the message Active books cannot be deleted. Deactivate them first.
-- Test
DELETE FROM dbo.Books WHERE BookID = 3;   -- should fail (book is active)
GO
UPDATE dbo.Books SET IsActive = 0 WHERE BookID = 3;
DELETE FROM dbo.Books WHERE BookID = 3;   -- should work now
SELECT * FROM dbo.Books;
DROP TRIGGER dbo.trg_Books_BlockActiveDelete;
