SQL Server Triggers — Part B: INSTEAD OF Triggers

Learning goals: Explain how INSTEAD OF triggers replace an attempted DML action, use both magic tables, and implement simple validation and soft deletion.

1. AFTER vs INSTEAD OF

AFTERINSTEAD OF
Runs after a successful statement's data change (before transaction commit)Runs in place of the attempted data change
Often used for auditingOften used to validate, redirect, or replace an action

An INSTEAD OF trigger does not automatically perform the original operation. The trigger must explicitly carry out the desired action. It fires once per statement, even for multiple rows.

2. Magic tables

For INSERT, inserted contains attempted new rows. For UPDATE, deleted has old values and inserted has proposed new values. For DELETE, deleted contains rows targeted for deletion.

4. INSTEAD OF INSERT: validate first

CREATE OR ALTER TRIGGER dbo.trg_Students_InsteadInsert
ON dbo.Students INSTEAD OF INSERT AS
BEGIN
 SET NOCOUNT ON;
 IF EXISTS (SELECT 1 FROM inserted WHERE Credits < 0)
  THROW 50001,'Credits cannot be negative.',1;
 INSERT INTO dbo.Students(StudentID,StudentName,Credits,IsActive)
 SELECT StudentID,StudentName,Credits,IsActive FROM inserted;
END;
GO
INSERT INTO dbo.Students(StudentID,StudentName,Credits)
VALUES (1,N'Ana',20),(2,N'Ben',35);
SELECT * FROM dbo.Students;
-- Run separately to observe the error:
INSERT INTO dbo.Students(StudentID,StudentName,Credits)
VALUES (3,N'Cara',-2);

Expected: Ana and Ben are inserted. Cara is rejected with an error. The trigger performs the valid insert itself.

5. INSTEAD OF UPDATE: reject invalid proposed values

CREATE OR ALTER TRIGGER dbo.trg_Students_InsteadUpdate
ON dbo.Students INSTEAD OF UPDATE AS
BEGIN
 SET NOCOUNT ON;
 IF EXISTS (SELECT 1 FROM inserted WHERE Credits < 0)
  THROW 50002,'Credits cannot be negative.',1;
 UPDATE s SET s.StudentName=i.StudentName,
  s.Credits=i.Credits, s.IsActive=i.IsActive
 FROM dbo.Students AS s JOIN inserted AS i ON s.StudentID=i.StudentID;
END;
GO
UPDATE dbo.Students SET Credits=Credits+3 WHERE StudentID=1;
SELECT StudentID,Credits FROM dbo.Students;
-- Run separately to observe the error:
UPDATE dbo.Students SET Credits=-10 WHERE StudentID=2;

Expected: Ana's credits become 23; Ben's attempted negative update is rejected. For simplicity, this exercise does not allow changes to StudentID.

6. INSTEAD OF DELETE: soft delete

CREATE OR ALTER TRIGGER dbo.trg_Students_InsteadDelete
ON dbo.Students INSTEAD OF DELETE AS
BEGIN
 SET NOCOUNT ON;
 UPDATE s SET IsActive=0
 FROM dbo.Students AS s JOIN deleted AS d ON s.StudentID=d.StudentID;
END;
GO
DELETE FROM dbo.Students WHERE StudentID=2;
SELECT StudentID,StudentName,IsActive FROM dbo.Students;

Expected: Ben still exists, but IsActive becomes 0. The DELETE statement was replaced by an UPDATE.

7. Important notes

SQL Server has restrictions on INSTEAD OF triggers (for example, an INSTEAD OF DELETE trigger cannot be defined on a table that is a target of a cascading DELETE foreign-key action). Trigger code should handle sets, not assume one row. Avoid writing to the same table without understanding recursion and nested-trigger behavior.
