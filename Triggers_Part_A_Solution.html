Triggers Part A Assignment — Answer Key

Instructor only — do not publish to students. Solutions, expected results, and grading notes for every task. Expected results assume the tasks were run in order on a fresh setup. AuditID values may have gaps, because rolled-back inserts still use identity numbers, so compare rows by content, not by AuditID.

Part A — Concept questions

A1. An AFTER trigger runs automatically when its event (INSERT, UPDATE, or DELETE) happens on its table. A stored procedure runs only when it is called explicitly with EXEC.
A2. inserted holds the new (after) version of each updated row; deleted holds the old (before) version.
A3. The trigger fires once, and deleted contains 4 rows. The trigger must use set-based code (e.g., INSERT … SELECT … FROM deleted) so that all 4 rows are handled, not just one.
A4. A DDL trigger fires when the database structure changes (CREATE, ALTER, DROP) and is attached to a database or the server. A LOGON trigger fires when a user connects to SQL Server, after the login is accepted, and can refuse the connection.
A5. A CHECK (Copies >= 1) constraint. Rules that need a trigger include anything that compares old and new values (Task 6), keeps history (Tasks 1–3), or writes to another table (Tasks 5, 7).
Grading: 0.5 point each; 0.25 for a partly correct answer.

Part B — Tasks 1–3

Task 1
CREATE OR ALTER TRIGGER dbo.trg_Books_AfterInsert
ON dbo.Books AFTER INSERT AS
BEGIN
 SET NOCOUNT ON;
 INSERT INTO dbo.BookAudit(BookID,ActionType,OldCopies,NewCopies)
 SELECT BookID,'INSERT',NULL,Copies FROM inserted;
END;
GO

Expected: 3 rows — INSERT for books 1, 2, 3 with NewCopies 3, 5, 4 and OldCopies NULL.

Task 2
CREATE OR ALTER TRIGGER dbo.trg_Books_AfterUpdate
ON dbo.Books AFTER UPDATE AS
BEGIN
 SET NOCOUNT ON;
 INSERT INTO dbo.BookAudit(BookID,ActionType,OldCopies,NewCopies)
 SELECT i.BookID,'UPDATE',d.Copies,i.Copies
 FROM inserted AS i JOIN deleted AS d ON i.BookID = d.BookID
 WHERE i.Copies <> d.Copies;
END;
GO

Expected: 2 new rows — UPDATE book 1 (3 → 5) and book 2 (5 → 7). The Author update adds no row. Common error: no WHERE filter, which produces an extra row for book 2 with 7 → 7.

Task 3
CREATE OR ALTER TRIGGER dbo.trg_Books_AfterDelete
ON dbo.Books AFTER DELETE AS
BEGIN
 SET NOCOUNT ON;
 INSERT INTO dbo.BookAudit(BookID,ActionType,OldCopies,NewCopies)
 SELECT BookID,'DELETE',Copies,NULL FROM deleted;
END;
GO

Expected: 2 new rows — INSERT book 4 (NULL → 1), produced by the Task 1 trigger, and DELETE book 4 (1 → NULL).

Grading for Tasks 1–3 (2 each): correct output 1, set-based logic 0.5, SET NOCOUNT ON and correct columns/ActionType 0.5. Using variables (single-row logic): maximum 1.

Part C — Tasks 4–8

Task 4
CREATE OR ALTER TRIGGER dbo.trg_Books_MinCopies
ON dbo.Books AFTER INSERT AS
BEGIN
 SET NOCOUNT ON;
 IF EXISTS (SELECT 1 FROM inserted WHERE Copies < 1)
 BEGIN
  ROLLBACK TRANSACTION;
  THROW 50001, N'A new book must have at least 1 copy.', 1;
 END
END;
GO

Expected: Msg 50001 for “Empty Book” (SSMS may also show Msg 3609, which is fine). Books then holds 1, 2, 3, 5. Audit: only one new row, INSERT book 5 (NULL → 2). The audit row for the failed insert was rolled back.

Task 5
CREATE OR ALTER TRIGGER dbo.trg_Books_TitleChange
ON dbo.Books AFTER UPDATE AS
BEGIN
 SET NOCOUNT ON;
 INSERT INTO dbo.LibraryLog(Message)
 SELECT N'Title changed from ' + d.Title + N' to ' + i.Title
 FROM inserted AS i JOIN deleted AS d ON i.BookID = d.BookID
 WHERE i.Title <> d.Title;
END;
GO

Expected: exactly one message — “Title changed from Database Systems to Fundamentals of Database Systems”. Using CONCAT instead is equally correct. No BookAudit rows, because Copies did not change.

Task 6
CREATE OR ALTER TRIGGER dbo.trg_Books_LimitReduction
ON dbo.Books AFTER UPDATE AS
BEGIN
 SET NOCOUNT ON;
 IF EXISTS (SELECT 1
            FROM inserted AS i JOIN deleted AS d ON i.BookID = d.BookID
            WHERE d.Copies - i.Copies > 5)
 BEGIN
  ROLLBACK TRANSACTION;
  THROW 50002, N'Copies cannot be reduced by more than 5 at once.', 1;
 END
END;
GO

Expected: Msg 50002 for the −6 update (7 → 1). The −2 update succeeds, and book 2 ends with 5 copies. Audit: one new row, UPDATE book 2 (7 → 5). Common error: checking i.Copies < 5 or using only inserted, which cannot see the size of the reduction.

Task 7
CREATE OR ALTER TRIGGER dbo.trg_Books_Archive
ON dbo.Books AFTER DELETE AS
BEGIN
 SET NOCOUNT ON;
 INSERT INTO dbo.BookArchive(BookID,Title,Author,Copies)
 SELECT BookID,Title,Author,Copies FROM deleted;
END;
GO

Expected: BookArchive holds book 5, Learning SQL, Beaulieu, 2. Audit: one new row, DELETE book 5 (2 → NULL).

Task 8
CREATE OR ALTER TRIGGER dbo.trg_Books_BlockActiveDelete
ON dbo.Books AFTER DELETE AS
BEGIN
 SET NOCOUNT ON;
 IF EXISTS (SELECT 1 FROM deleted WHERE IsActive = 1)
 BEGIN
  ROLLBACK TRANSACTION;
  THROW 50003, N'Active books cannot be deleted. Deactivate them first.', 1;
 END
END;
GO

Expected: Msg 50003 on the first delete. After deactivation the delete succeeds. Books then holds only 1 and 2. Audit: one new row, DELETE book 3 (4 → NULL). The deactivation adds no audit row, because Copies did not change.

Grading for Tasks 4–8 (1.5 each): correct logic and test results 1, correct pseudo-table (and join where needed) 0.25, trigger dropped 0.25. Wrong error number or message: −0.25.

Part D — Tasks 9–10

Task 9 (a) — Problems (any three; 1 point):
  1. Single-row logic: @title holds one title, so a 2-row insert logs only one message.
  2. Zero-row failure: if an INSERT…SELECT inserts no rows, @title is NULL, so the message is NULL. Inserting it into the NOT NULL Message column raises an error that cancels the user's statement.
  3. No SET NOCOUNT ON.
  4. The row the variable picks is not predictable when there are several rows.
(b) Corrected trigger (0.5 point):
CREATE OR ALTER TRIGGER dbo.trg_Books_NewBookLog
ON dbo.Books AFTER INSERT AS
BEGIN
 SET NOCOUNT ON;
 INSERT INTO dbo.LibraryLog(Message)
 SELECT N'New book: ' + Title FROM inserted;
END;
GO

(c) Expected (0.5 point): two new messages, “New book: Head First SQL” and “New book: SQL Cookbook”. Audit: INSERT book 6 (NULL → 2) and INSERT book 7 (NULL → 3).
