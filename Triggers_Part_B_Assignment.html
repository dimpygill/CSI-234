Part B Assignment — INSTEAD OF Triggers (20 Points)

Total: 20 points. Use SQL Server Management Studio and a practice database. Run the Part B tutorial setup in a separate practice database or reset the tables. Submit one .sql file containing code and short answers as SQL comments, plus screenshots or copied query results.

Questions

1. Compare trigger timing (4 points)

Explain AFTER versus INSTEAD OF. What happens to the attempted DELETE if an INSTEAD OF DELETE trigger only updates IsActive?

2. Magic tables (4 points)

For an INSTEAD OF UPDATE, explain the contents of inserted and deleted. Does the original UPDATE automatically occur?

3. INSTEAD OF INSERT (4 points)

Write a trigger that rejects any INSERT statement containing a negative Credits value and inserts all valid proposed rows. Demonstrate one accepted INSERT and one rejected INSERT.

4. INSTEAD OF UPDATE (4 points)

Write a trigger that rejects negative Credits and otherwise updates StudentName, Credits, and IsActive for all affected students. Demonstrate an accepted and rejected update. Assume StudentID is not updated.

5. INSTEAD OF DELETE (4 points)

Write a trigger that performs soft deletion by setting IsActive=0 instead of removing rows. Attempt to delete two students in one statement. Show that both remain in Students and are inactive.
